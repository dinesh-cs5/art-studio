Art Studio

A web application for exploring traditional Indian paintings, booking wall paintings, and requesting custom pottery.

Live Demo

https://artstudiopaintings.lovable.app

Planned Features

- Browse paintings and prices.
- Check painting availability.
- Request wall-painting bookings.
- Submit pottery requests.
- Provide customer and studio workflows.
